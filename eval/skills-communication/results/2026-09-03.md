## Verdict

Candidate wins with no dimension going backwards. The margin is small because the
baseline is already terse and does not over-build. The gains are exactly the two
things the candidate adds: plainer English and asking before guessing on an
ambiguous task.

Caveat: question-first is a nudge, not a guarantee. Candidate run 2 still gave a
default caching config instead of asking. If we want asking to be more reliable,
the T2-style ambiguity may need a sharper cue than "ask when blocked."

## What was tested

## How to reproduce

Give one agent `arms/baseline.md` as its only style rule and another
`arms/candidate.md`, have each answer `tasks.md`, run each 3+ times, and score
every reply with `rubric.md`. Ship the candidate only if it wins with no
dimension going backwards.
